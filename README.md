# 📍 BibleMap

성경을 읽을 때 **지도와 함께 보면 이해에 큰 도움이 되는 핵심 여정**만 모아, 실제 지도 위에서 경로 애니메이션·말씀 구절과 함께 보는 인터랙티브 학습 보조 도구입니다.

## ✨ 기능

- **큐레이션된 8개 테마** — 성경 이해에 특히 도움이 되는 지도만 선별
  - 구약: 아브라함의 여정 · 출애굽 경로
  - 신약: 예수님의 생애와 사역 · 바울의 1~3차 전도여행 · 로마 압송 항해
- **여정 재생(▶)** — 출발지부터 도착지까지 경로가 그려지며 카메라가 따라가는 애니메이션
- **지점별 말씀 연결** — 각 지점마다 관련 성경 구절과 해설 제공
- **번호 마커 + 경로선** — 이동 순서를 한눈에 파악
- **검색** — 지명·성경 구절·테마로 빠르게 찾기 (예: `에베소`, `출애굽`, `사도행전 27`)
- **현대 지명 병기** — 옛 지명과 오늘날 위치를 함께 표시

## 🚀 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 정적 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

## 🧱 기술 스택

- Vite + React + TypeScript
- Leaflet + OpenStreetMap (무료 타일, API 키 불필요)

## 🗂️ 구조

```
src/
  data/maps.ts          # 테마·지점·좌표·말씀 데이터 (여기만 고치면 지도 추가/수정 가능)
  components/
    Sidebar.tsx         # 테마 목록 + 검색
    MapView.tsx         # 지도, 마커, 경로, 애니메이션
  App.tsx               # 상태 관리 + 재생/상세 패널
```

## ➕ 지도 추가하기

`src/data/maps.ts`의 `THEMES` 배열에 항목을 추가하면 됩니다. 각 지점은 위도/경도 좌표와
관련 성경 구절(`refs`), 해설(`desc`)을 가집니다. 좌표는 학습 보조용 추정 위치입니다.

## ⚠️ 참고

지명의 위치와 경로는 학습을 돕기 위한 **추정·단순화된 표현**이며, 일부 지명은 정확한 고고학적
위치에 대해 학자마다 견해가 다를 수 있습니다.
